## Instalacja

1. Rozpakuj ZIP
2. **Pobierz chart.js**: https://cdn.jsdelivr.net/npm/chart.js@4.5.1/dist/chart.umd.min.js
3. Zapisz jako `chart.js` w tym folderze
4. `chrome://extensions` → Tryb deweloperski → Wczytaj rozpakowane
5. W ustawieniach wpisz Point ID `60545`
